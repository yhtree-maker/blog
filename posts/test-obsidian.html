Obsidian × Claude Code 打通记

2026-07-25

为什么需要打通这两个工具？

Obsidian 是最好的移动端笔记应用之一，Claude Code 是最强的 AI 写作助手。

核心洞察：不要试图让两个工具互相通信，而是让它们共享同一个文件系统。

实现步骤

  1. 安装 Termux 和 PRoot Distro
  2. 执行 termux-setup-storage
  3. 创建符号链接打通目录
  4. 安装 rclone 同步到网盘

最终效果

# 写作命令
claude "读取 notes/ 下的采访笔记，写一篇 2000 字的报道"

现在在 Obsidian 里就能看到生成的草稿，继续编辑后运行 bash /root/blog/deploy.sh 发布。
